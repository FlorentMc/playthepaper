* **Smithsonian Magazine article pages now return 403** to this routine's `curl`. The RSS feed itself
  is fine (200, 284 items), so candidates can still be spotted, but nothing can be quoted from them,
  which removes a whole source from use. Worth deciding whether to pursue a licence or drop the row
  from SOURCES.
* **The NASA science feed is not well-formed XML** (parse error at line 8). It returns 200, so it looks
  healthy, but a strict parser cannot read it. A tolerant parser or `apod.nasa.gov` would be needed to
  use NASA as a source.
* **Quanta returns a 301** from `api.quantamagazine.org/feed/` with no body. Following the redirect
  would need the target host in the network allowlist.
* With Smithsonian unquotable, NASA unparseable and Quanta redirecting, **ScienceDaily is effectively
  the only working science source**, which is why recent editions keep drawing their science story
  from it.
