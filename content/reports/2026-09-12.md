## For the owner

* **The toolchain install failed on the first attempt.** `bootstrap.sh` streams the Flutter tarball
  straight into `tar`; after 50 minutes the transfer died with `curl: (56) Recv failure: Connection
  reset by peer`, leaving a half-extracted SDK with no `packages/` directory, and the script exited
  0 because its output was piped. A re-run would have skipped the download (it only tests for
  `$HOME/flutter/bin/flutter`) and failed at `flutter pub get`. I removed the partial install,
  re-fetched the archive to a file with `curl -C -` and retries (7 minutes the second time),
  extracted it, and then ran `bootstrap.sh` unchanged, which printed `bootstrap: ok`. Nothing in
  the repository was modified to get there. Worth considering: download to a file with resume and
  verify before extracting, and check the SDK is complete rather than just present.
* On a normal 02:15 UTC run this failure would have cost the edition. It only fit here because the
  manual run had the whole day.
* Three days of the Current Events portal with no usable general headline is unusual; if it recurs,
  the general-headline rule may need a second allowlisted general-news source.
