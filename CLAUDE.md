# Daypencil

Flutter app: a free daily puzzle paper. Read `docs/ARCHITECTURE.md` before changing anything;
it is the module contract. `docs/daypencil-concept-and-implementation.md` is the product brief
(its Cloudflare and donation sections are superseded: hosting is a static directory on the
existing DigitalOcean droplet, the publisher is a Claude cloud routine, and there are no donations).

Commands: `flutter analyze`, `flutter test`, `flutter run -d chrome`, `dart run tool/validate.dart content`.
